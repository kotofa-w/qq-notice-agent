# 可选CalDAV配置工具

网关支持可写HTTPS CalDAV日历，可使用fruux或兼容服务。没有配置提供者时，日历能力关闭。普通通知摘要与日历授权分别处理。

首次部署优先阅读[通用安装指南](../../docs/GETTING_STARTED.md)，通过私有环境文件配置。此目录还保留Windows DPAPI部署工具：`setup-credentials.ps1`在本机输入设备凭据，`discover.ps1`执行只读发现，`configure-gateway.ps1`把选择的日历追加到已存在的受保护网关配置。

这些工具依赖自行创建的`private/`目录及Windows当前用户环境；不附带可直接登录的设备凭据或日历地址。不要提交`private/`、发现结果或日志。

日历候选必须通过原文时间证据、目标授权和订阅策略；日历写入带提醒属性，手机端同步和弹窗需要客户端另行配置。真实写入测试具有外部副作用，不属于离线测试或CI。
