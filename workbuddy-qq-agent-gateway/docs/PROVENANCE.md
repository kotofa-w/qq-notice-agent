# 代码来源

本公开快照在[DrivingGodJ/workbuddy-qq-agent-gateway](https://github.com/DrivingGodJ/workbuddy-qq-agent-gateway)基础上继续开发，其代码包含源自[Epic0522/Codex-Remote-Contact](https://github.com/Epic0522/Codex-Remote-Contact)的实现。独立仓库和全新Git历史不表示从零重写，不改变原作者权利。

现有来源记录曾使用原始上游提交[8412335](https://github.com/Epic0522/Codex-Remote-Contact/commit/8412335abbe38cd0633aff7cc1a6486283b7defc)做历史文件对比；该旧统计不适用于本次快照，因此不再把旧文件数量或已移除平台文件列为当前清单。当前路径以[公开文件索引](../../docs/FILE_INDEX.md)为准。

保留及扩展的能力包括WorkBuddy/CodeBuddy桥、网页控制台、持久会话、受控QQ工具、通知订阅、负责人、CalDAV候选与执行恢复、历史预览、有限连接恢复扫描以及隔离测试。文件新增、拆分或改写并不自动表示其中每一行均为原创。

QQ/NapCat、模型CLI、Python SDK和其他依赖由用户另行安装。当前产品入口面向Windows，历史平台自动化不是本快照承诺的能力。网页演示与图片使用合成数据，非部署用户记录。
