# 公开快照与验证范围

此仓库发布Windows QQ通知网关的独立源码快照。初始提交不包含原部署仓库的Git历史、作者邮箱、分支或运行配置；后续公开修改在本仓库继续记录。

## 发布内容

- 网关源码、网页、模型SDK桥、公开配置模板、合成演示资源及隔离测试。
- 可复用的Windows运行脚本及CalDAV凭据配置工具。第三方QQ桥、模型CLI与Python环境需要另外准备。
- 通知整理、负责人、日程候选、执行恢复及有限历史补漏。自动历史扫描只生成预览，实际补做需要人工确认。

## 去敏范围

发布从已跟踪源码的明确清单生成，不复制工作区全部文件。实机使用指南、历史方案和部署验收记录不发布，说明改写为通用安装步骤。移除真实QQ账号、设备用户名、机器路径、网络接口地址、旧部署标识与私有仓库链接；运行脚本改用一致的通用任务名称。

真实会话、消息、订阅、日程、文件、图片、表情收藏、凭据、进程记录、日志、备份、第三方软件包和虚拟环境均不发布。网页演示截图使用合成数据，不能视为真实QQ或模型验收。

私有环境变量没有默认账号或令牌；`100000001`、`100000002`等只用于明确的隔离测试。自行部署时填写自己的独立OWNER/BOT账号及私有配置，不把测试身份当作有效账号。

## 检查方式

发布前检查实际Git暂存对象、已知部署标识、个人路径、私有端点和常见凭据格式，核对相对链接及图片元数据，并在独立快照执行离线测试。仓库还提供Windows GitHub Actions，安装SDK依赖后运行Node与Python测试及暂存对象审计。

这些检查验证源码行为和发布范围。新机器的QQ登录、桥版本、模型权限、日历访问和手机同步仍需自行验收；本仓库不预置任何在线服务，不保证所有历史都可找回。扫描失败、截断和未知覆盖会显示人工核查提示。
